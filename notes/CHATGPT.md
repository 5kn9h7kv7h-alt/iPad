# ChatGPTとの分担フロー

Claude Code（実装・テスト・取り込み）とChatGPT（案出し・文面・設計レビュー）を、コピー&ペーストでつなぐ手順です。
ChatGPTのAPIは使いません（費用0円のまま）。

## 役割分担

| 担当 | 内容 |
|---|---|
| ChatGPT | 画面デザイン案、日本語の言い回し（音声コマンドのバリエーション）、設計レビュー、コードのたたき台 |
| Claude Code | ChatGPTの案の取り込み、既存コードとの整合、テスト実行、不具合修正 |
| あなた | 両者の橋渡し（貼り付け）、実機（iPad）での確認、採否の判断 |

## 手順

1. `npm run bundle` で `notes/chatgpt-context.md` を作る（仕様の要約と全ソースが入る）。
2. ChatGPTの新しいチャットに、そのファイルを添付する（添付できない場合は本文に貼る）。
3. 下の「依頼テンプレート」から1つ選び、`【やりたいこと】` を書き換えて送る。
4. ChatGPTの返答（ファイル全文のコードブロック）を、そのままClaude Codeに貼り付けて「取り込んでテストして」と伝える。
5. Claude Codeが取り込み → `npm run build` / `npm test` / `npm run test:e2e` → 結果を報告する。
6. 失敗した場合は、Claude Codeが原因を調べて直す。ChatGPTに戻す必要があるのは設計判断が要るときだけ。

## 依頼テンプレート

### A. 音声コマンドの言い回しを増やす
```
添付の文脈ファイルを読んでください。core/voice.js のルールベース解析について、
日本語の自然な言い回しで、現在の正規表現では解釈できなさそうな指示を30個挙げ、
それぞれ期待する intent / projectId / title を表にしてください。
そのうえで voice.js の修正案と、tests/unit/voice.test.js に追加するテストを、ファイル全文で返してください。
誤操作を避けるため、変更系の指示は曖昧なら unknown にしてください。
```

### B. 画面デザインの改善案
```
添付の文脈ファイルを読んでください。iPad（820x1180）のタッチ操作を優先し、
【やりたいこと】のための画面改善案を出してください。
styles.css と app.js の変更はファイル全文で返してください。タップ領域は44px以上、依存ライブラリは追加しないでください。
```

### C. 設計レビュー
```
添付の文脈ファイルを読んでください。セキュリティ、データ損失、アクセシビリティ、iPad Safari特有の問題の観点でレビューし、
重大度順に、再現手順つきで指摘してください。コードは直さず、指摘だけで構いません。
```

### D. 次の機能（クラウド同期など）の設計案
```
添付の文脈ファイルを読んでください。storage/repository.js のインターフェースを保ったまま、
【クラウド同期】を追加する設計案を出してください。無料枠の条件は「要確認」と明記し、断定しないでください。
認証方式、データの競合解決、オフライン時の挙動、費用が発生する可能性のある項目を分けて書いてください。
```

## 注意

- 文脈ファイルには、このアプリのソースコードだけが入ります。APIキーや個人情報は含まれません（このアプリはそれらを扱いません）。
- 貼り付ける前に、`notes/chatgpt-context.md` の中身を一度確認してください。外部サービスへの送信になります。
- ChatGPTの返答は、そのまま信用せず、必ずテストを通してから採用します。
