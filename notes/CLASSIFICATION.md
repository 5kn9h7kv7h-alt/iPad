# 家計簿の分類の基準

持ち主が決めた基準。サイトの自動分類（public/js/core/receipt.js）と、Claudeが写真から分類するときの両方で使う。

| 分類 | 基準 | 例 |
|---|---|---|
| 食費 | 食べられる物・飲める物 | 牛乳、野菜、パン、お菓子、飲料 |
| 日用品 | 使うと減っていく消耗品 | 洗剤、ティッシュ、シャンプー、ラップ、電池 |
| 雑費 | めったに買い換えない物 | フライパン、鍋、ごみ箱、包丁、食器、収納ケース |
| 外食 | 飲食店・カフェでの支払い | ランチ、ドリンク |
| その他 | 上のどれにも当てはまらない物 | |

迷う物は、レシートの確認画面で直す。直した分類はサイトが覚えて、次回から同じ品名に使う。
